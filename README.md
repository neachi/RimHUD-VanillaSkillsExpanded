# RimHUD - Vanilla Skills Expanded

A RimWorld mod that displays [Vanilla Skills Expanded](https://steamcommunity.com/sharedfiles/filedetails/?id=3400246558) expertise on [RimHUD](https://steamcommunity.com/sharedfiles/filedetails/?id=1508850027).

### Requirements
- Harmony
- [RimHUD](https://steamcommunity.com/sharedfiles/filedetails/?id=1508850027)
- [Vanilla Skills Expanded](https://steamcommunity.com/sharedfiles/filedetails/?id=3400246558)

### How to Use
1. Open the RimHUD layout editor.
2. Click **Add (External / Other Mods)** on a row or slot.
3. Select `[VSE] Expertise (Bar)` or `[VSE] Expertise (Text)` and place it where you like.

---

Vanilla Skills Expanded で追加される「専門技能」を RimHUD のHUD上に配置・表示できるようにする連携MODです。

### 使い方
1. RimHUDの設定画面からレイアウト編集を開きます。
2. 配置したい行や枠で「他MOD 追加」を選択します。
3. `[VSE] 専門技能 (バー)` または `[VSE] 専門技能 (テキスト)` を選んで配置します。
